# 运动控制自检清单

## 采集时序
- [ ] 时序图覆盖所有信号：编码器 → 触发 → 光源 → 曝光 → 读出
- [ ] 全循环（8 角度）时间 < 2s，含 20% 余量
- [ ] LED 点亮与相机曝光窗口重叠 ≥ 95%
- [ ] 各角度之间光源切换无串扰（上一盏完全熄灭后下一盏才亮）
- [ ] 时序参数以实测为准（已在实际硬件上验证）

## 控制器
- [ ] 控制器 CPU 负荷 < 60%（含通讯和逻辑）
- [ ] 高速 I/O 响应时间 ≤ 1μs
- [ ] 总线周期时间 ≤ 1ms（EtherCAT）/ ≤ 4ms（PROFINET）
- [ ] 有 ≥ 20% I/O 预留

## 触发
- [ ] 相机硬触发走线长度 ≤ 5m（或加驱动）
- [ ] 触发信号有屏蔽，远离动力线
- [ ] 触发抖动实测 ≤ 1μs
- [ ] 编码器触发位置精度 ≤ ±0.02mm

## 编码器
- [ ] 编码器分辨率满足位置触发精度要求
- [ ] 信号类型与控制器输入匹配（TTL/HTL/差分）
- [ ] 编码器与传送轮无打滑（机械连接可靠）
- [ ] 差分信号传输（抗干扰），单端信号 < 2m

## 异常处理
- [ ] 光源故障能检测（电流/亮度监控），检测时间 < 100ms
- [ ] 相机掉帧能检测（帧序号或超时），不产生"幽灵"数据
- [ ] 编码器丢失信号时设备停机，不继续采集
- [ ] 急停响应时间 < 50ms，安全继电器 SIL3/PL e
- [ ] 故障后恢复流程明确（不残留状态）

## 电气接口
- [ ] 与产线握手信号定义完整，已与工厂自动化确认
- [ ] MES 数据格式与工厂 IT 确认
- [ ] 电源分配有保险丝/断路器，每个设备独立保护
- [ ] 强弱电分离，信号线屏蔽接地
- [ ] 接地：单点接地，模拟地-数字地分离

## 接口
- [ ] 为 05-algorithm 提供了触发时序、编码器分辨率、图像采集参数
- [ ] 触发方案与 03-optics 的相机/光源参数匹配
- [ ] 控制架构与 02-mechanical 的传送机构/分选执行器匹配
