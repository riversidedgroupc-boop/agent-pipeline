# 机械结构设计自检清单

## 结构完整性
- [ ] 整机重量有估算值
- [ ] 主体材料有选型依据
- [ ] 焊接件去应力处理已标注
- [ ] 关键承载位置安全系数 ≥ 3

## 相机安装
- [ ] 每个相机有独立 XYZ 调节自由度
- [ ] 调节后锁紧方式明确
- [ ] 相机接口尺寸与选型匹配
- [ ] 线缆有固定路径，运动件用拖链

## 光源安装
- [ ] 光源布局覆盖所有检测角度
- [ ] 高度角可调范围满足不同产品需求
- [ ] 偏振片旋转调节有刻度指示
- [ ] LED 散热路径经过计算

## 传送与张紧
- [ ] 传送速度覆盖产线最大速度 × 1.2
- [ ] 张紧力范围可调
- [ ] 导向机构适应产品尺寸公差范围
- [ ] 编码器安装无打滑风险

## 调焦
- [ ] 调焦行程覆盖所有镜头工作距离
- [ ] 重复定位有实测数据支撑
- [ ] 调焦后锁紧不改变光轴位置

## 防震
- [ ] 一阶固有频率 ≥ 80 Hz 已验证（仿真或计算）
- [ ] 隔振元件选型与载荷匹配
- [ ] 外部振动源（电机、传送带）已识别

## 气路
- [ ] 喷嘴不遮挡光路
- [ ] 吹扫压力不足以损伤产品表面
- [ ] 气路接头有防松标记

## 维护
- [ ] 日常点检可在 5 min 内完成
- [ ] 易损件有标准件号，可快速采购
- [ ] 校准用基准件有图纸

## 安全性
- [ ] 运动部件有防护罩
- [ ] 急停按钮间距 ≤ 2m
- [ ] 强光/激光区域有互锁或防护
- [ ] 电气柜 IP 等级匹配现场环境

## BOM
- [ ] 外购件不少于 2 个可选品牌
- [ ] 加工件标注了关键尺寸公差
- [ ] 标准件优先用国标/ISO

## 接口
- [ ] 为 03-optics 提供了相机-产品几何关系
- [ ] 安装空间数据已传递
- [ ] 与上游 01-pm 的产品规格无冲突
