# 产品经理自检清单

## 检测对象完整性
- [ ] 所有材质类型已列出，并注明各材质占比
- [ ] 尺寸范围有上限和下限，而非仅"最大/最小"
- [ ] 表面状态涵盖产线各工艺段（来料→半成品→成品）
- [ ] 产品照片或图纸已附上（如可用）

## 缺陷定义
- [ ] 每种缺陷有明确的操作性定义（不是仅靠经验判断）
- [ ] 最小检出尺寸已量化（长 × 宽 × 深 或等效直径）
- [ ] 检出率目标有统计置信度说明（如 ≥ 98% 意味着每 100 件允许漏 ≤2 件）
- [ ] 严重等级划分有业务逻辑支撑（与客户确认过）
- [ ] 缺陷参考图已收集（如可用）

## 节拍与产能
- [ ] 最大线速度来自于产线实际数据，不是估算
- [ ] 单件检测周期包含采集时间 + 算法处理时间 + 分选时间
- [ ] 产能目标有年/月/日三级分解
- [ ] 考虑了换型时间和维护停机时间

## 产线接口
- [ ] 安装空间标注了不可改动的约束（柱子、管道、人行通道）
- [ ] 来料方式与上游设备衔接方式已明确
- [ ] 分选方式与下游料框/料架匹配
- [ ] MES 接口字段与工厂 IT 确认过
- [ ] 电源、气源容量有余量（≥ 20%）

## 环境条件
- [ ] 温度范围覆盖产线极端工况（夏天最高、冬天最低）
- [ ] 粉尘等级决定了防护等级和除尘方案
- [ ] 振动源频率和幅值已测量或估算，供防震设计用

## 验收标准
- [ ] FAT 和 SAT 的样件来自实际产品，不是标准样板
- [ ] 缺陷样件覆盖所有缺陷类型 + 各 3 个等级（边界尺寸/典型尺寸/极端尺寸）
- [ ] 验收通过标准与检出率目标一致

## 成本与交期
- [ ] 整机成本包含安装、调试、培训费用
- [ ] 交期考虑了外购件货期（高功率激光器、特殊镜头等长货期件）
- [ ] ROI 周期已估算（设备成本 / 年节省人工成本）

## 向下游传递
- [ ] 规格书中标注了每个参数对哪个下游 Agent 最关键
- [ ] 不确定的参数标注"待验证"并有验证计划
- [ ] 与 02-mechanical 确认过检测通道空间的可行性
