# 整机评审自检清单

## 接口一致性
- [ ] 每个上游→下游接口都做了逐参数比对
- [ ] 关键参数（线速度、分辨率、节拍、检出率）在传递链路中数值一致
- [ ] 发现的不一致项有明确的"以谁为准"的裁决
- [ ] 下游对上游参数的"引用"有明确的文档出处（不是口头传递）

## 规格追溯
- [ ] 01-pm 的每一条量化需求都在追溯矩阵中有对应
- [ ] "未覆盖"项有说明（暂不实现 / 后续版本 / 不可行）
- [ ] "部分覆盖"项有差距分析（差多少、影响多大）
- [ ] 没有隐性降级（需求悄悄降低但没有记录）

## 风险
- [ ] 至少识别了 10 个跨系统集成风险
- [ ] 每个高/中风险项有缓解措施和责任人
- [ ] 考虑了最坏情况叠加（最高速 + 最小缺陷 + 最短处理时间）
- [ ] 考虑了现场特有风险（粉尘/振动/温度/操作员水平）
- [ ] 各环节余量 ≥ 20%（审查确认，不是信任设计师自述）

## 集成测试
- [ ] FAT 测试覆盖所有机械/电气/光学功能
- [ ] SAT 测试覆盖真实产品 × 真实环境 × 连续运行
- [ ] 关键接口测试排在 P0 优先级
- [ ] 测试方法有定量判定标准（不是"看起来正常"）
- [ ] 缺陷样件已准备好（数量 ≥ 30 个/类型）

## 合规与安全
- [ ] 适用的国标/ISO/CE 标准已列出
- [ ] 电气安全已审查（接地、绝缘、漏电流）
- [ ] 急停回路响应时间 < 50ms
- [ ] 运动部件防护罩符合安全距离标准
- [ ] 激光/强光区域有防护或互锁（如适用）

## 评审结论
- [ ] 结论明确（通过/有条件通过/不通过），不含糊
- [ ] 条件项可验证（每条有责任人、截止日期、验证方法）
- [ ] 遗留问题有跟踪计划（不是"以后再说"）
- [ ] 评审结论与各子系统 Agent 确认过（无重大分歧）
