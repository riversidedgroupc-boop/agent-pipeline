# 算法设计自检清单

## 预处理
- [ ] ROI 提取在多种光照条件下稳定（不因反光/阴影偏移）
- [ ] 降噪不抹掉最小缺陷的边缘信号（σ 选择有测试依据）
- [ ] 配准精度达到亚像素级（实测 ±0.5px 以内）
- [ ] 亮度归一化后各图均值偏差 ≤ 5
- [ ] 预处理总耗时 ≤ 200ms

## 融合
- [ ] 加权融合的 α/β/γ 参数有实际样本调优记录（不是纯经验值）
- [ ] 反光抑制阈值有数据支撑（取正常样本亮度的 μ+3σ）
- [ ] 阴影补偿不引入伪影
- [ ] 融合图清晰度（Laplacian Variance）不差于任何单张原图
- [ ] 权重热力图可视化正确（高贡献区域对应实际缺陷位置）

## 缺陷检测 — OpenCV 传统管线
- [ ] 每种缺陷类型至少有一种传统算法覆盖（OpenCV baseline）
- [ ] Canny 双阈值有数据支撑（取梯度直方图的 p75/p90 分位）
- [ ] HoughLinesP 参数（minLineLength/maxLineGap）已按缺陷尺寸范围设定
- [ ] 形态学操作核大小与最小缺陷尺寸匹配
- [ ] DoG σ1/σ2 比值 1.6:1（经典 Marr-Hildreth 比例）

## 缺陷检测 — YOLO (v11/v12/v26)
- [ ] 训练集 ≥ 500 样本/类，按缺陷类型+等级分层采样
- [ ] 数据增强：Mosaic/RandomFlip/HSV 扰动已配置
- [ ] Anchor-Free 模式已启用（YOLOv26 默认），无需锚框聚类
- [ ] YOLOv26 C3k2-Fusion 模块已评估对小缺陷（< 10px）的提升效果
- [ ] YOLOv26 Adaptive IoU 损失已针对低对比度缺陷场景调参
- [ ] 若缺陷以长条形为主，YOLOv26 OBB（旋转框）模式已评估
- [ ] mAP@0.5 ≥ 0.85（对于 ≥ 500 样本/类的场景）
- [ ] NMS IoU 阈值已针对密集缺陷场景调优
- [ ] YOLO 输出格式（xywh/xyxy + class + confidence）与后续分级逻辑对接

## 缺陷检测 — 异常检测（冷启动）
- [ ] 仅用合格品训练，训练集 ≥ 100 张（覆盖正常变异）
- [ ] 异常分数阈值基于正常样本分布（如 μ+3σ 或 99.7 分位）
- [ ] 异常热力图分辨率不低于输入尺寸的 1/4

## 缺陷检测 — 通用
- [ ] 路线 A（融合后检测）的检出率不显著低于路线 B（分别检测后合并）
- [ ] 路线 B 回溯验证逻辑正确（N 张以上确认才判缺陷）
- [ ] 检测阈值基于正常样本统计（μ+kσ），不是拍脑袋
- [ ] 检测结果包含缺陷位置（bbox/mask）、类型、置信度
- [ ] OpenCV 传统管线始终保留作为深度学习推理的 backup

## 分类分级
- [ ] 分级规则与 01-pm 的严重等级定义一致
- [ ] 多缺陷共存时有明确的优先级裁决逻辑
- [ ] 分级结果经客户确认（不要出现"客户认为A级实际只算B级"）

## 算力与节拍
- [ ] 融合 + 检测总时间 ≤ 500ms（含预处理）
- [ ] 算法复杂度 O(N²) 以内
- [ ] 若超时，降级策略已定义（如加权→中位数）
- [ ] GPU/CPU 占用率 < 80%（留余量给系统进程）

## 部署
- [ ] 推理框架与目标平台兼容
- [ ] 量化精度损失 < 1%（Recall 下降 ≤ 0.5%）
- [ ] 采集流水线与处理流水线不阻塞
- [ ] 异常情况（图像损坏、内存不足）有处理策略

## 验证
- [ ] 训练集 / 验证集 / 测试集按缺陷类型分层采样，无数据泄露
- [ ] 每类缺陷至少有 30 个独立样本用于测试
- [ ] 评价指标分缺陷类型统计（不只看总体）
- [ ] 对未见缺陷类型有泛化测试（保留一部分缺陷类型不参与训练）

## 接口
- [ ] 融合算法已对齐 04-motion 的采集时序（关联角度与图像序号）
- [ ] 畸变参数来自 03-optics 的镜头选型，已用于配准
- [ ] 缺陷判定结果格式与 06-review 的评审模板兼容
