# 光学设计自检清单

## 光源设计
- [ ] 波长选择有材质反射率数据支撑
- [ ] 光源数量与角度间隔覆盖所有检测方向（任意方向划痕 ≥ 2 个角度可见）
- [ ] 扩散板透光率已计入光通量计算
- [ ] PWM 频率避开相机行频 ± 500Hz
- [ ] LED 结温 ≤ 80°C 已验证（热仿真或计算）
- [ ] 亮度调节范围留有 ±30% 余量

## 镜头选型
- [ ] 焦距与工作距离、视野匹配（公式已验证）
- [ ] 像方分辨率 ≥ 传感器 Nyquist 频率
- [ ] 畸变参数已标注，供算法配准使用
- [ ] 景深覆盖产品可能的离焦范围（振动 + 产品公差）
- [ ] 镜头接口与相机接口一致

## 相机选型
- [ ] 分辨率满足 Nyquist：1px ≤ 1/3 最小缺陷尺寸
- [ ] 全局快门（除非有充分理由用卷帘快门）
- [ ] 帧率 ≥ 采集节拍 × 安全系数 1.2
- [ ] 像元尺寸与镜头 F/# 匹配（不过采样或欠采样）
- [ ] 数据接口带宽满足帧率 × 分辨率 × 位深

## 偏振
- [ ] 消光比 ≥ 100:1（除非成本极度敏感）
- [ ] 偏振片透过率已考虑（进光量损失补偿）
- [ ] 正交校准方法可复现，有定量判定标准
- [ ] 检偏器旋转调节有锁紧和刻度

## 防护与散热
- [ ] 镜头防护方案不影响成像质量（无额外反射/鬼影）
- [ ] 光源散热路径经过计算或仿真
- [ ] 散热气流不吹向光路（防止灰尘飞扬和空气扰动）
- [ ] IP 等级匹配现场环境

## 安装调试
- [ ] 装调流程可量化（不是凭经验"看着调"）
- [ ] 标定板和基准件有设计图纸
- [ ] 视场均匀性验收标准明确（≥ 85%）
- [ ] 光学装调时间 ≤ 30 min（目标）

## 接口
- [ ] 为 04-motion 提供了曝光时间、频闪时序、触发模式
- [ ] 为 05-algorithm 提供了分辨率、像元尺寸、畸变参数、工作距离
- [ ] 光学方案与 02-mechanical 的安装空间无冲突
